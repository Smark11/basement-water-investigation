# Basement Water Investigation — Weatogue, CT

Why is water coming up through a glued-down basement floor while the sump pit stays dry?

A multi-agent AI research investigation (August 1, 2026): ranked diagnosis, an eight-step
diagnostic test plan, and a three-tier fix plan with Connecticut-area pricing.

**Read the report:** open `index.html`, or view the published GitHub Pages site for this repo.

- `index.html` — the full report (self-contained, no external dependencies)
- `photos/` — homeowner photos, downscaled and with all metadata (EXIF/GPS) removed
- `RESEARCH_LOG.md` — step-by-step log of how the investigation was conducted

Produced by a Claude multi-agent research workflow: five parallel domain researchers
(local hydrology, differential diagnosis, sump systems, flooring forensics,
remediation & costs — 63 web lookups, 131 sources) followed by an adversarial
lead-investigator synthesis. Not a professional engineering opinion; see the
disclaimer in the report footer.
